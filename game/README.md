# モンファス! 〜モンスターフュージョン〜

スマホのブラウザで遊べる、2Dドット絵のオリジナルモンスター育成・合成ゲームです。
外部ライブラリ不要・HTML/CSS/JSのみで動作します。

## 遊び方(スマホで開く方法)

このフォルダを静的サイトとして配信すれば、すぐ遊べます。

- **GitHub Pages**: リポジトリの Settings → Pages でブランチを公開し、
  `https://<ユーザー名>.github.io/manga-issue-log/game/` を開く
- **ローカル**: `npx serve` などでこのフォルダを配信し、スマホから開く

データは端末の localStorage に自動セーブされます。

## ゲーム内容

| 機能 | 説明 |
|------|------|
| 🥚 探索 | タマゴを見つけて新しいモンスターを仲間にする |
| 🌀 合成 | 2匹を選んで合成。**見た目(頭+体)・色・タイプ・ステータスを受け継いだ新モンスターが誕生**。合成体同士の再合成も可能で、ランク(★)が上がるほど強くなる |
| ⚔️ バトル | 野生モンスターとのターン制バトル。タイプ相性(こうかばつぐん!)、クリティカル、レベルアップあり。勝つと相手が仲間になることも |

## 特徴

- 16×16 ドット絵をその場で描画(合成結果も無限パターン)
- ほのお/みず/くさ/でんき/いわ/やみ/ひかり/りゅう の8タイプ
- 派手な演出: パーティクル、画面シェイク、フラッシュ、衝撃波リング、紙吹雪、合成時の渦巻きエフェクト
- WebAudio によるレトロ効果音(🔊ボタンでON/OFF)
- 全操作タップのみ・縦画面スマホ最適化
